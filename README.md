# Наедине — демонстрация вёрстки

Адаптивная главная страница загородного дома с демонстрационным калькулятором стоимости. React + TypeScript + CSS, сборщик esbuild. Калькулятор работает локально в браузере; сервер и база данных не нужны.

## Посмотреть сайт

https://marinanigma.github.io/naedine-demo/

## Что можно посмотреть

- Первый экран, описание дома, галерею, форматы отдыха, правила и FAQ.
- Калькулятор дат проживания, состава гостей и дней сауны.
- Разбивку стоимости и расчётную предоплату 30%.

Добавлены два изображения, восстановленные из предоставленного владельцем рекламного коллажа: дом на закате и лужайка у дома. Надписи и элементы сторис удалены с помощью ИИ; отдельные детали могут отличаться от оригинальных снимков. Это обработанные изображения, а не оригинальные документальные фотографии. При получении исходных фото их следует заменить. Реальные отзывы и контакты не добавлены. Приём заявок, административная часть и хранение данных гостей в демонстрацию не входят. Расчёт не проверяет занятость и не подтверждает бронирование.

## Структура

- `src/components/` — компоненты страницы и калькулятора.
- `src/modules/` — тексты, тарифы, валидация и функции расчёта.
- `src/style.css` — стили.
- `src/main.tsx` — подключение страницы и демонстрационного расчёта.
- `assets/photos/` — подготовленные WebP-изображения в нескольких размерах.
- `build.mjs` — сборка интерфейса и копирование изображений.
- `docs/` — готовые HTML, CSS и JavaScript для GitHub Pages.

## Изменить сайт

Нужен Node.js 22.12 или новее:

```sh
npm ci
npm run build
```

После изменения исходников пересобрать сайт и добавить в коммит также обновлённую папку `docs/`. GitHub Pages публикует её из ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Пароли, токены и настройки сервера для сборки не требуются.

## Запустить локально без npm

При установленном Python 3:

```sh
python3 -m http.server 8000 --directory docs
```

Затем открыть http://localhost:8000. Для остановки — Ctrl+C.
